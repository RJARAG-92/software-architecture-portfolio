# Software Architecture Portfolio

Portfolio de proyectos y casos de estudio enfocados en diseño de software, decisiones de arquitectura y construcción de soluciones orientadas a problemas reales.

El objetivo de este repositorio es documentar no solo el resultado de cada proyecto, sino también el contexto, las restricciones, las decisiones tomadas y los trade-offs considerados durante su desarrollo.

## Proyectos

### 🍽️ El Batán - Control de Personal

Aplicación de escritorio desarrollada para apoyar la gestión operativa del personal de un pequeño negocio.

El proyecto cubre el ciclo completo de construcción y puesta en marcha de una solución: análisis del problema, diseño, implementación, persistencia de datos, seguridad, pruebas, backups, versionado, distribución y marcha blanca.

**Tecnologías principales**

`.NET 8` · `WPF` · `Entity Framework Core` · `SQLite` · `xUnit` · `Inno Setup`

**Estado:** `v0.9.0` · Marcha blanca

➡️ [Ver caso de estudio](projects/el-batan-control-personal/README.md)

## Enfoque

Los casos de estudio de este repositorio buscan documentar principalmente:

- Contexto y problema a resolver.
- Requisitos y restricciones.
- Decisiones de arquitectura.
- Alternativas consideradas.
- Trade-offs.
- Diseño de la solución.
- Estrategias de persistencia y recuperación.
- Despliegue y evolución.
- Aprendizajes obtenidos durante el uso real.

> Una solución no necesita ser compleja para requerir buenas decisiones de arquitectura.
